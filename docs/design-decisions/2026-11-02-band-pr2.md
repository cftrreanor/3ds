## Follow-up light check (2026-11-02)

Review: screenshots in docs/design-reviews/2026-11-02-band-pr2-v2/ (consultant, Software Engineer,
UX Content Manager). The consultant's verdict: ship after fixes. All fixed in this PR:

| Finding | Severity | Done |
|---|---|---|
| "Fix address" refused for past directors and co-hosts | 3 | Saved as the person fixing it; marked moved only after the new invitation is on its way |
| "Open now" or an earlier opening day left scheduled invitations waiting | 3 | They go out when registration opens, whatever day was chosen; "Open registration now" sends them at once |
| Corrected-email box too narrow on phones | 3 | Full width on phones |
| Every failure blamed the address | 2 | Our failures say "We couldn't send this one" with Send again; refused addresses say to check for typos |
| A director could be emailed twice | 2 | Each invitation is claimed before it's sent |
| Long lists cut off part-way | 2 | Sends stop cleanly before the time limit; the rest go next time |
| Re-inviting while registration opens later never sent | 2 | Waiting invitations are reset to unsent |
| No way to cancel a scheduled invitation | 2 | "Don't send" |
| Wording ("Open now", "Schedule", midnight, the 7-day line, close-early) | 1–2 | As suggested |
