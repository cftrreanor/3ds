# Who reviews what

**Full panel** (all seven roles plus the consultant) for most changes. **Light check** for small
tweaks, with only the roles listed. The consultant is included in a light check whenever the
row says so.

| Change | Size | Reviewers |
|---|---|---|
| New feature, new page, new flow, or a new event type | Full panel | All seven roles + consultant |
| Reordering steps, changing what a page leads with, or adding or removing a step | Full panel | All seven roles + consultant |
| **Wording only:** in-app labels, buttons, help text, errors, or empty states | Light check | Content Manager |
| **Wording that customers see first:** website, emails, sign-up pages, or pricing and plan names | Light check | Content Manager + Marketing Manager |
| **Visual only:** color, spacing, icons, badges, or dark mode | Light check | UI Designer + consultant (accessibility only) |
| Moving one element on one page, or a layout change with the same steps | Light check | UX Designer + UI Designer + consultant (flow and accessibility) |
| Adding one field or setting | Light check | UX Designer + Content Manager + Software Engineer + Product Owner |
| Anything touching children's details, phone numbers, or who can see what | Add to any size | Software Engineer, always |
| Pricing, plans, limits, or what's included | Light check | Product Manager + Marketing Manager + Content Manager |
| A bug fix with no visible change | No panel | Normal code checks only |

## Pairings

Some roles review best as a pair. They still review separately, but their findings are read side
by side in the report.

- **Content Manager + Marketing Manager:** the words people read, and what those words promise
- **UX Designer + UI Designer:** how it flows, and how it looks while flowing
- **Product Owner + Software Engineer:** what "done" means, and what it costs to get there
- **Product Manager + Marketing Manager:** why it exists, and how we'll describe it

## Moving up

A light check becomes a full panel if:
- any reviewer rates a finding 3 or 4,
- the change turns out to touch more than one page's flow, or
- the owner asks for one.
